# ✨ Key Features

- 👑 **Dynasty Profile Manager:** Save and switch between different campaign setups  
- 🧩 **Mod Organizer:** Manage gameplay mods, total conversions, and tweaks  
- 💾 **Auto Save Backup:** Protect dynastic progress and save states  
- 🛡 **Safe Configuration Layer:** No modification of core game files  
- 🌍 **Cross-Platform Support:** Windows, macOS, Linux compatible  
- ⚡ **Performance Optimization:** Smoother gameplay with large mod lists  
- 🏰 **Campaign Scenario Switcher:** Quickly change dynasties and story setups  
- 🔄 **Auto Updates:** Keeps mod environment current  
- 🎁 **Open-Source & MIT Licensed:** Free and community-driven
